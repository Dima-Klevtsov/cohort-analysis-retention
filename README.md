## Цель проекта

Проанализировать уровень удержания клиентов в интернет-магазине (retention в оформление заказа) и определить насколько продукт удовлетворяет потребности клиентов, соответствует рынку (product/market fit - PMF).

## Результаты

В рамках аналитической работы были выполнены следующие задачи:
1. Исследован набор данных и определить, какой вид заказа будет учитываться в retention
2. Построить месячный retention
3. Проанализировать, чему равен медианный retention 1-го месяца (т.е. взять retention 1-ого месяца для всех когорт и посчитать по этим числам медиану)
5. Найти когорту с самым высоким retention на 3-й месяц.
6. Проиллюстрировать результаты релевантной визуализацией, удобной для восприятия.
